# HTML का टावर (Tower of HTML)

> **HTML की शिक्षा को विश्व स्तर पर सुलभ बनाएं — चाहे हार्डवेयर, इंटरनेट कनेक्टिविटी या डिवाइस की उम्र कुछ भी हो।**

**Tower of HTML** एक न्यूनतम, ऑफलाइन-फर्स्ट शैक्षिक प्लेटफॉर्म है जिसे शुरुआत से HTML के मूल सिद्धांत सिखाने के लिए डिज़ाइन किया गया है। संपूर्ण एप्लिकेशन एक ही, स्व-निहित `.html` फ़ाइल के भीतर मौजूद है, जिसमें कोई बाहरी निर्भरता, फ्रेमवर्क, बिल्ड स्टेप्स या सर्वर आवश्यकताएं नहीं हैं।

## 🎯 डिज़ाइन दर्शन और मुख्य मिशन

### हम कौन सी समस्या हल करते हैं
अधिकांश आधुनिक वेब डेवलपमेंट शिक्षण प्लेटफॉर्म महत्वपूर्ण बाधाएं उत्पन्न करते हैं:
1. **इंटरनेट कनेक्टिविटी पर निर्भरता**: ऑनलाइन IDE और LMS प्लेटफॉर्म कम-बैंडविड्थ या ऑफलाइन वातावरण में विफल हो जाते हैं।
2. **आधुनिक हार्डवेयर आवश्यकताएँ**: आधुनिक उपकरणों के लिए आधुनिक ऑपरेटिंग सिस्टम, उच्च RAM और भारी ब्राउज़र इंजन की आवश्यकता होती है, जो पुराने हार्डवेयर वाले उपयोगकर्ताओं को बाहर कर देते हैं।
3. **जटिलता का बोझ**: शुरुआती लोग अक्सर HTML की एक भी लाइन लिखने से पहले बिल्ड टूल्स, फ्रेमवर्क और पैकेज मैनेजरों से घबरा जाते हैं।
4. **वेंडर लॉक-इन (Vendor Lock-in)**: उपयोगकर्ता की प्रगति तीसरे पक्ष के प्लेटफॉर्म की उपलब्धता और अनिवार्य खाता निर्माण पर निर्भर करती है।

### हमारा समाधान
Tower of HTML चार मुख्य प्रतिबद्धताओं पर काम करता है:
* **सुविधाओं से पहले पहुंच**: UI फ्रेमवर्क पर मूल संगतता और स्पष्ट पठनीयता को प्राथमिकता देता है।
* **मनोरंजन से अधिक शिक्षा**: एक संरचित, मंजिल-दर-मंजिल प्रगति जहां सख्त, निष्पक्ष मूल्यांकन के माध्यम से महारत हासिल की जाती है।
* **प्लेटफॉर्म पर स्वामित्व**: उपयोगकर्ता बिना अनुमति मांगे प्रोजेक्ट को अनिश्चित काल तक अपने पास रख सकते हैं, डाउनलोड कर सकते हैं, संशोधित कर सकते हैं और चला सकते हैं।
* **चतुराई से अधिक स्पष्टता**: बिना किसी उलझाव (obfuscation) या ट्रांसपाइलेशन (transpilation) के स्पष्ट, पठनीय कोड में लिखा गया है ताकि सीखने वाले सीधे स्रोत कोड से ही निरीक्षण कर सकें और सीख सकें।

## ✨ मुख्य विशेषताएँ

* **100% ऑफलाइन-फर्स्ट**: नेटवर्क एक्सेस की आवश्यकता के बिना किसी भी वेब ब्राउज़र में स्थानीय रूप से चलता है।
* **सिंगल-फाइल आर्किटेक्चर**: सब कुछ (CSS, JS, कंटेंट) एक पोर्टेबल `index.html` फ़ाइल (~50KB) के अंदर रहता है।
* **लिगेसी इंजन सपोर्ट**: पुराने हार्डवेयर पर कार्यात्मक निष्पादन सुनिश्चित करने के लिए लिगेसी-सुरक्षित जावास्क्रिप्ट (ES3/ES5 मानक) का उपयोग करके बनाया गया है।
* **शून्य निर्भरता**: बाहरी लाइब्रेरी, पैकेज मैनेजर, फोंट या CDN लिंक से मुक्त।
* **स्तर-कोड प्रणाली (Level-Code System)**: सरल पासवर्ड हैश तंत्र उपयोगकर्ताओं को स्थानीय स्टोरेज के बिना किसी भी ब्राउज़र या डिवाइस पर प्रगति फिर से शुरू करने की अनुमति देता है।
* **टर्मिनल थीम्स**: इंटरफ़ेस में सीधे सुलभ अनुकूलन योग्य दृश्य मोड (Matrix, Amber, DOS Blue, Light, Cyber)।

## 🌐 सार्वभौमिक पहुंच और हार्डवेयर संगतता

क्योंकि Tower of HTML आधुनिक वेब निर्भरताओं के बिना लिगेसी-सुरक्षित जावास्क्रिप्ट में लिखा गया है, यह उपकरणों और ऑपरेटिंग सिस्टम के एक विस्तृत स्पेक्ट्रम में मज़बूती से चलता है:

| डिवाइस / प्लेटफॉर्म | परिचालन स्थिति | नोट्स |
| :--- | :---: | :--- |
| **1995 Pentium PC** | ✅ समर्थित | Windows 95/98, Internet Explorer 6+ |
| **Chromebooks** | ✅ समर्थित | सभी Chrome ब्राउज़र संस्करण |
| **लिगेसी मोबाइल (iPhone 4S / Android 4.0)** | ✅ समर्थित | नेटिव मोबाइल ब्राउज़र (Safari 5+, Android WebKit) |
| **आधुनिक लैपटॉप और डेस्कटॉप** | ✅ समर्थित | Chrome, Firefox, Safari, Edge, Opera |
| **Raspberry Pi** | ✅ समर्थित | हल्के ब्राउज़र इंजन |
| **कम-संसाधन वाली शैक्षिक प्रयोगशालाएँ** | ✅ समर्थित | किसी प्रशासनिक विशेषाधिकार या इंस्टॉलेशन की आवश्यकता नहीं |

यह डिज़ाइन कम संसाधनों वाले वातावरण में शिक्षकों को प्रोजेक्ट को एक बार डाउनलोड करने और USB या स्थानीय फ़ाइल साझाकरण के माध्यम से छात्रों को वितरित करने की अनुमति देता है।

## 🚀 शुरुआत कैसे करें

1. अपने डिवाइस पर `index.html` फ़ाइल डाउनलोड करें या सहेजें।
2. `index.html` पर डबल-क्लिक करें (या इसे किसी भी वेब ब्राउज़र के साथ खोलें)।
3. वर्तमान मंजिल (floor) के लिए प्रॉम्प्ट पढ़ें, इनपुट फ़ील्ड में अपना HTML स्निपेट टाइप करें, और **CHECK CODE** (कोड जांचें) पर क्लिक करें।
4. किसी मंजिल को पूरा करने पर, भविष्य के सत्रों में या विभिन्न उपकरणों पर अपनी प्रगति को फिर से शुरू करने के लिए जनरेट किए गए **Level Code** (स्तर कोड) को लिख लें या कॉपी कर लें।

## 🏗️ वास्तुकला और कार्यप्रणाली (Architecture & Mechanics)

एकल `index.html` फ़ाइल निर्भरता-मुक्त वातावरण बनाए रखते हुए शिक्षण सामग्री से निष्पादन तर्क को सख्ती से अलग करती है:


index.html
├── <head>
│   └── <style> : टर्मिनल स्टाइलिंग, उत्तरदायी लेआउट, दृश्य थीम
└── <body>
├── UI Container : गेम स्क्रीन, इनपुट टर्मिनल, आउटपुट दृश्य
└── <script>
├── levels[] Array : सादा-पाठ अनुदेशात्मक डेटा और सत्यापन नियम
└── Engine Logic   : DOM अपडेट, लेवल-कोड सत्यापन, प्रगति स्थिति

### डिज़ाइन प्रतिबद्धताएं
- **इनलाइन CSS**: एक ही `<style>` ब्लॉक के भीतर एम्बेडेड।
- **इनलाइन JavaScript**: एक ही `<script>` ब्लॉक के भीतर एम्बेडेड।
- **ES3/ES5 मानक**: ट्रांसपाइलेशन की आवश्यकता वाले आधुनिक ES6+ सुविधाओं के बजाय मानक लूप निर्माण और ES3/ES5 सिंटैक्स (`var`, `for` लूप) का उपयोग करता है।

## 🔑 स्तर-कोड प्रगति प्रणाली (Level-Code Progression System)

ब्राउज़र स्टोरेज API (`localStorage`, `indexedDB`, या कुकीज़) पर निर्भर रहने के बजाय, प्रगति को छोटे, मानव-पठनीय **स्तर कोड (Level Codes)** के माध्यम से सहेजा जाता है।

### यह कैसे काम करता है
1. एक मंजिल पूरी करने पर, एप्लिकेशन एक विशिष्ट कोड प्रदर्शित करता है (जैसे, `L5-PARA`)।
2. उपयोगकर्ता कोड को कॉपी कर सकते हैं, सहेज सकते हैं, या लिख सकते हैं।
3. बाद के सत्रों में, **JUMP TO FLOOR** फ़ील्ड में कोड दर्ज करने से तुरंत उस मंजिल की स्थिति लोड हो जाती है।

### लाभ
- **क्रॉस-ब्राउज़र और क्रॉस-डिवाइस**: पुराने मोबाइल फोन और डेस्कटॉप कंप्यूटर के बीच निर्बाध रूप से ले जाएं।
- **शून्य गोपनीयता पदचिह्न (Zero Privacy Footprint)**: उपयोगकर्ताओं को ट्रैक किए बिना, कुकीज़ संग्रहीत किए बिना, या वेब अनुरोध किए बिना संचालित होता है।
- **कोई API निर्भरता नहीं**: स्थानीय स्टोरेज विनिर्देशों के अस्तित्व में आने से पहले बनाए गए ब्राउज़रों पर भी कार्य करता है।

## 🛠️ अनुकूलन और विस्तार दिशानिर्देश

क्योंकि संपूर्ण एप्लिकेशन लॉजिक एक क्लीन जावास्क्रिप्ट ऐरे (array) में संग्रहीत है, मंजिलों को जोड़ने या संशोधित करने के लिए `index.html` के भीतर `levels` ऐरे को संपादित करने की आवश्यकता होती है।

### नई मंजिल जोड़ना

    desc: "Create an opening header tag.",

        var clean = input.toLowerCase().replace(/\s+/g, '');
        return clean.indexOf("<header>") !== -1;
    }
}

 * मानक स्ट्रिंग संचालन का उपयोग करें: .indexOf(), .toLowerCase() और बुनियादी रेगुलर एक्सप्रेशंस जैसे तरीकों पर भरोसा करें।
 * व्हाट्सस्पेस को लचीले ढंग से संभालें: सख्त स्ट्रिंग तुलनाओं से बचें जो अतिरिक्त ट्रेलिंग स्पेस या लाइन ब्रेक के कारण विफल हो जाती हैं।
