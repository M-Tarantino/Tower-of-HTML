# HTML 之塔 (Tower of HTML)

> **让 HTML 教育实现普惠 —— 无论硬件、互联网连接或设备新旧如何。**

**Tower of HTML** 是一个极简、离线优先（Offline-First）的教育平台，旨在从零开始教授 HTML 基础知识。整个应用程序包含在一个独立、自包含的 `.html` 文件中，没有任何外部依赖、框架、构建步骤或服务器要求。

## 🎯 设计理念与核心使命

### 我们解决的问题
绝大多数现代网页开发学习平台都存在明显的门槛：
1. **依赖互联网连接**：在线 IDE 和 LMS 平台在低带宽或离线环境中无法使用。
2. **现代硬件要求高**：现代工具需要较新的操作系统、大内存以及笨重的浏览器引擎，将老旧硬件的用户拒之门外。
3. **复杂度过高**：初学者在编写第一行 HTML 之前，往往就被各种构建工具、框架和包管理器搞得不知所措。
4. **平台锁定 (Vendor Lock-in)**：用户的学习进度完全依附于第三方平台的可用性以及强制性的账号注册。

### 我们的解决方案
Tower of HTML 秉承四大核心承诺：
* **普惠优先于特性**：比起 UI 框架，更优先保证原始兼容性和清晰的可读性。
* **教育优先于娱乐**：采用循序渐进、逐层推进的结构，通过严格且公平的验证机制来确保真正掌握知识。
* **自主权优先于平台**：用户可以无限期地拥有、下载、修改和运行该项目，无需征得任何许可。
* **清晰优先于巧妙**：采用清晰、可读的代码编写，没有任何混淆（obfuscation）或转译（transpilation），学习者可以直接从源代码中进行检查和学习。

## ✨ 核心功能

* **100% 离线优先**：无需联网，可在任何网页浏览器中本地运行。
* **单文件架构**：所有内容（CSS、JS、文本内容）均包含在一个可移植的 `index.html` 文件中（约 50KB）。
* **旧版引擎支持**：使用对旧版安全兼容的 JavaScript（ES3/ES5 标准）构建，确保能够在老旧硬件上正常执行。
* **零依赖**：不包含任何外部库、包管理器、字体或 CDN 链接。
* **关卡代码系统**：通过简单的密码哈希机制，允许用户在任何浏览器或设备上恢复进度，无需使用本地存储（localStorage）。
* **终端主题**：提供可在界面中直接切换的可定制视觉模式（Matrix、Amber、DOS Blue、Light、Cyber）。

## 🚀 快速入门

1. 将 `index.html` 文件下载或保存到您的设备中。
2. 双击 `index.html`（或使用任意网页浏览器打开它）。
3. 阅读当前层数的提示，在输入框中输入您的 HTML 代码片段，然后点击 **CHECK CODE**（检查代码）。
4. 完成某一层后，记录或复制生成的 **Level Code**（关卡代码），以便在以后的会话中或不同设备上恢复您的进度。

## 🏗️ 架构与运行机制

单一的 `index.html` 文件在保持零依赖环境的同时，严格将执行逻辑与教学内容相分离：


index.html
├── <head>
│   └── <style> : 终端样式、自适应布局、视觉主题
└── <body>
├── UI 容器 : 游戏屏幕、输入终端、输出视图
└── <script>
├── levels[] 数组 : 纯文本教学数据与验证规则
└── 引擎逻辑       : DOM 更新、关卡代码验证、进度状态

### 设计承诺
- **内联 CSS**：嵌入在单个 `<style>` 块中。
- **内联 JavaScript**：嵌入在单个 `<script>` 块中。
- **ES3/ES5 标准**：使用标准的循环结构和 ES3/ES5 语法（`var`、`for` 循环），而不是需要转译的现代 ES6+ 特性。

## 🔑 关卡代码进度系统

系统不依赖浏览器的存储 API（如 `localStorage`、`indexedDB` 或 Cookie），而是通过简短、人类可读的 **关卡代码 (Level Codes)** 来保存进度。

### 工作原理
1. 完成某一关后，应用程序会显示一个唯一的代码（例如 `L5-PARA`）。
2. 用户可以复制、保存或抄写该代码。
3. 在之后的会话中，只需将代码输入到 **JUMP TO FLOOR**（跳转到楼层）输入框中，即可立即加载该关卡的状态。

### 优势
- **跨浏览器与跨设备**：在老旧手机和台式电脑之间无缝切换。
- **零隐私足迹**：运行过程中不追踪用户、不存储 Cookie、不发起任何网络请求。
- **无 API 依赖**：甚至能在本地存储规范出现之前的古老浏览器上运行。

## 🛠️ 自定义与扩展指南

由于整个应用程序的逻辑都存储在一个干净的 JavaScript 数组中，因此添加或修改关卡只需编辑 `index.html` 中的 `levels` 数组即可。

### 添加新关卡

```javascript
{
    id: "L52-HEADER",
    title: "Floor 52: Header Semantic Element",
    info: "The <header> tag represents introductory content or navigation links.",
    hint: "Type <header> to open the header section.",
    desc: "Create an opening header tag.",
    check: function(input) {
        var clean = input.toLowerCase().replace(/\s+/g, '');
        return clean.indexOf("<header>") !== -1;
    }
}

验证设计指南
在添加验证规则时，请遵守项目的通用兼容性规则：
 * 使用标准字符串操作：依赖 .indexOf()、.toLowerCase() 以及基本的正则表达式等方法。
 * 灵活处理空白字符：避免因多余的尾随空格或换行符而导致失败的严格字符串比较。
 * 保持兼容性：切勿引入 ES6 方法（如 .includes()），除非在文件内部原生实现了 polyfill。
